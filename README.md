# Alinda Messages 💬

A free, web-based message collection app — find the perfect message for any occasion.

**Built by Alinda Creation Hub**

## Features

- **25+ categories** — Good morning, good night, birthday, love, friendship, motivational, apology, congratulations, sympathy, thank you, get well, anniversary, new baby, graduation, encouragement, holidays, inspirational, short & sweet, funny, romantic, condolences, wedding, new job, retirement, spiritual
- **Search** — Find messages by keyword
- **Filter** — Browse by category
- **One-tap copy** — Copy any message to clipboard
- **Share** — Send via native device share sheet
- **Verification gate** — Age + Terms confirmation before access
- **No sign-up, no data collection** — Privacy-first

## Tech Stack

- HTML5, CSS3, vanilla JavaScript (no frameworks)
- Cloudflare Pages (deployment)
- Google Fonts (Poppins, Dancing Script)
